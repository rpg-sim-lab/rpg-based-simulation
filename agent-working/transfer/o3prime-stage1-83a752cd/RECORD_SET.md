## Stop rules (nothing is retried or deleted; a stop is reported as stopped)
1. Preflight abort: a tree not equal to its ls-tree, `data/runs` or a `.git` in a tree, freeze differs, a kit file sha256 differs from record.env, another heavy job, MemAvailable under 3 GiB, disk under 2 GiB free on OUT or /.
2. Disk floor before every process: a clean stop (`STOPPED_DISK_FLOOR_BEFORE_<cell>`, `disk_floor_stop.json`); the summarizer does not run; the seal does.
3. Freeze change after any process: `VOID_INTERPRETER_CHANGED`, the remaining processes are not started.
4. A crash or a watcher kill: any return code outside {0, 5, 6, 7} stops the run (`STOPPED_AT_<cell>`). 5 = WIRING_MISMATCH (including a motive read error, which also raises), 6 = a control that never fired, 7 = ledger not live: the kit itself marks such a spy cell invalid (the summarizer says so); the run goes on.
5. The 25-min first-process rule and the 4 h run rule: **both are checked only AFTER each process ends**, so a hung process is stopped only by the watcher (memory), the manual stop, or the operator.
6. A `runner.json` that cannot be written makes the run non-COMPLETE (`RECORD_NOT_WRITTEN`, RC 6; every kit python call runs with cd $KIT and PYTHONPATH).
**Suggested manual hard stop: 1 h 45 min after RUN START** (about 1.75 x the expected wall; the 4 h rule would not catch a hang inside one process).
