# TCK-20261117-SLIME-AND-DRAGONKIN-NEED-A-NON-FOOD-BIRTH-CONDITION

## Title
Slime and dragonkin get a birth condition that does not depend on hunger

## Status
OPEN

## Tier
standard

## Type
feature

## Priority
P3

## Request Summary
This is a backlog item and not part of M1. The owner ruled on B2 on 2026-11-17 (#715 6950737100, "OK + backlog (Recommended)"): in M1 only kinds that eat get births (ECOL-06, decision 67). Undead, spirit, slime and dragonkin are excluded, so their numbers only fall. This ticket gives slime and dragonkin, which are arguably living, a birth condition that does not use the fed line. The owner's ruling also says the ubuntu RPG lane files this ticket with the births batch.

## Scope
- Rule work first. Decide the condition, for example the kind's own need line or a regional source, and how the ECOL-06 text is amended. Both are rpg-designer's call.
- Then add the reproduction profile fields for that condition in content, and handle it in the one births system.

## Out of Scope
- Undead and spirit, which are not living.
- Any M1 item.

## Acceptance Criteria
- Slime and dragonkin can be born under a declared condition that does not use hunger.
- The bars are the same as the births own-job (ECOL-06), adapted to the new condition.
